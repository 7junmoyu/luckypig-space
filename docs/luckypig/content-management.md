# 维护个人介绍与作品

本轮使用 Halo 社区版内容后台，独立前台通过匿名公开接口读取内容。上传、发布/下线、重启持久化及独立备份恢复已通过。现已录入首批三件个人开发录屏，后续文字直接在后台修改，见 [录屏作品记录](recordings-v1.md) 和 [M5 验收](m5-validation.md)。

## 首次启动

在 `space-web/` 执行 `npm run dev`。脚本生成本地配置，启动 Halo 与 PostgreSQL，再启动网站。

- 网站：http://127.0.0.1:4173
- 后台：http://127.0.0.1:8090/console
- 新环境首次访问后台按引导创建管理员。当前本机已初始化，用户名 `space-admin`，凭据仅保存在被 Git 忽略的 `space-web/artifacts/local-admin.json`（0600），不要再次初始化或提交此文件。
- 数据库密码由脚本随机生成，保存在被 Git 忽略的 `deploy/.env`。数据库和附件分别保存在 Compose 命名卷中。
- 首次拉取镜像与初始化可能需要一些时间。网站不会把后台故障伪装成演示内容。

## 创建作品分类

在后台文章分类中创建以下分类，别名（slug）必须与表格一致：

| 分类 | 别名 | 作用 |
| --- | --- | --- |
| 作品 | `space-project` | 网站只收录选择了此分类的公开文章 |
| AI 创作 | `ai` | 前台 AI 分类 |
| DevOps | `devops` | 前台 DevOps 分类 |
| Agent 实践 | `agent` | 前台 Agent 分类 |

一篇作品选择“作品”和一个主题分类。仅选择“作品”时归入“其他作品”。其他普通博客文章不会混入作品列表。

## 发布第一条多媒体作品

1. 附件 → 使用本地存储策略，上传 `space-web/fixtures/upload-samples/` 中的 `cover.png`、`clip.mp4`、`notes.txt`。本机已在默认策略中增加“文档”（DOCUMENT），单文件上限仍为 200MB；新环境也需配置。Markdown 的 MIME 不在默认文档白名单，尚未支持直接上传。
2. 新建文章，标题填写“多媒体发布链路测试”，手动摘要填写用途与素材说明。
3. 选择“作品”和“AI 创作”分类，设置封面为已上传的图片。
4. 在正文中插入图片、视频和文件链接，再加入外部演示链接。默认富文本编辑器已通过图片、视频、TXT 和外链的保存/发布/重新编辑测试。下面是正文结构示意，用后台实际链接替换占位地址，不要把 HTML 源码当普通文字粘贴。
5. 在文章设置 → 元数据中填写已安装的中文字段：内容性质、作者贡献、展示形式、来源等。示例保持“参考/测试”，真实作品再选择个人作品。保存并发布，允许公开访问，不设置为私密或定时未来发布。
6. 刷新网站查看作品；后台更新后列表会在可见页面中每 30 秒重读一次，打开详情时会重新请求发布内容。

```html
<h2>测试目的</h2>
<p>这是一条自建功能测试记录，不代表真实工作成果。</p>
<img src="/upload/实际图片地址.png" alt="确定性测试图">
<video controls playsinline src="/upload/实际视频地址.mp4"></video>
<p><a href="/upload/实际文档地址.txt">下载测试说明文档</a></p>
<p><a href="https://github.com/luckypig1209/luckypig-space">打开项目源码</a></p>
```

这些测试素材由本地 FFmpeg 生成，并非 AI 创作成果或第三方作品。视频为 3 秒 H.264 无声测试片。

## 作品补充字段

Halo 标题、摘要、分类、标签、封面、正文和发布时间直接映射到前台；首版无需修改 Halo 核心或安装自定义插件。额外字段通过中文元数据表单维护，下面是对应技术键名，日常操作不必手填键名：

| 键 | 值示例 / 用途 |
| --- | --- |
| `space.luckypig.dev/demo` | `true` 为示例；只有确认是个人作品时填写 `false`。缺省按示例处理 |
| `space.luckypig.dev/authorship` | 例如“自建功能测试记录，非真实工作成果”；或真实作品中的个人职责 |
| `space.luckypig.dev/subtitle` | 可选副标题 |
| `space.luckypig.dev/format` | 例如“录屏 / 图片 / 文档” |
| `space.luckypig.dev/source-name` | 参考项目或外链名称 |
| `space.luckypig.dev/source-url` | 对应 HTTP(S) 来源链接 |
| `space.luckypig.dev/media-credit` | 图片、视频来源与许可说明 |

前台只投影这些已约定的字段，不透传 Halo 其他元数据或草稿快照。中文表单定义在 `deploy/space-post-annotations.json`，本机已安装并关联当前激活后台主题 `theme-earth`；更换后台主题时需同步调整关联，独立前台视觉不受影响。

## 个人介绍

创建一篇公开文章，将文章别名设置为 `space-profile`：标题作为显示名称，摘要作为简介，正文为公开介绍，标签作为兴趣方向。不要为此文章选择作品分类。资料会由 `/api/profile` 读取；未录入的履历和技能不会自动补写。

## 下线与附件

文章移回草稿、设为私密或删除后，公开作品接口和旧详情链接会重新校验状态，不再返回该作品。已打开的页面不会撤回访客此前看到的内容。

Halo 本地附件是公开文件。文章下线不等于撤销已知附件 URL 的访问；需要撤回文件时还要在附件管理中处理。私密原始资料不应作为公开附件上传。

## 首版正文支持

支持常用标题、段落、列表、代码、表格、图片、原生视频和链接。文档链接可以下载；PDF 由浏览器按能力打开。前台重建允许的 DOM 节点，过滤脚本、iframe、事件属性和活动 URL。插件私有节点与任意第三方嵌入暂不支持。

## 手动验收

发布后在 `space-web/` 运行 `npm run test:halo`，检查真实接口可读取含图片、视频、链接的正文。该脚本只读，不修改站点；它不能代替以下手动步骤：

- 浏览器播放 MP4 并拖动进度，打开图片和下载文档。
- 编辑摘要并再次发布，验证网页及公开接口更新。
- 下线作品，验证列表、搜索、旧详情和本地检索会话不再引用。
- 重启 Halo 与数据库，验证文章及附件持久化。
- 对照 `halo-live-validation.md` 记录实际结果；未执行的项目不标记通过。

依据：[Halo 官方安装文档](https://docs.halo.run/guide/install/docker-compose)、[公开 API 与认证说明](https://docs.halo.run/developer-guide/restful-api/introduction)，以及当前 Fork 的公开文章接口与文章设置源码。运行版本使用稳定版 `2.27.2`；Fork 源码目前为 `2.28.0-SNAPSHOT`，需要继续验证版本兼容性。
