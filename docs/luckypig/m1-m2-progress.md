## 本轮新增

- 分类、标签、关键词和页码保存在 URL 中；刷新恢复，浏览器返回保留筛选，支持清除筛选。
- 列表每页四条；数据减少时校正当前页；API 和页面共用筛选函数，API 新增 `tag` 查询参数。
- 图片放大查看，Esc 返回作品详情；所有示例和后台作品都有复制链接入口。
- 演示模式第一个案例接入本地 PNG、三秒 MP4 和 Markdown，明确标注为非 AI 创作、非个人工作成果；仅三个固定文件可通过 `/demo-media/` 访问。
- 个人名称、介绍随公开资料刷新；未变更的数据不会重建卡片和标签选项，避免自动刷新中断点击和焦点。
- 补充详情超时与请求失败提示。
- 新增 `npm run halo:wait`，通过 HTTP 等待后台就绪，不调用 Docker socket。
- 增强 `npm run test:halo`：真实文章必须包含本地上传的图片、视频、文档，验证附件可读及视频 Range 206；此检查仍需真实 Halo 运行，尚未通过。
