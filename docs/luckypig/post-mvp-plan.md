## 本轮交付（N1 + N2）

2026-11-11新增N3交付，详见[N3验证记录](n3-release-validation.md)及[部署说明](../../deploy/release/README.md)。用户主机amd64目标构建及metadata已确认，无需重复构建；服务器及域名明确后进入N4。以下保留N1/N2原交付范围。

- 首页主导航与作品区提供“面试导览”，来源筛选为全部/个人/参考。`view=interview` 强制个人范围；面试链接清除无关查询参数，定位作品区。单作品分享保留公开筛选和导览状态。
- 个人作品只认内容层明确的 `demo=false`；未知标记按参考处理。原始录屏、封面、作品正文和后台发布记录未修改。
- 导览按“观看演示 → 阅读过程与贡献 → 对话追问”组织；入口通过现有 `/api/chat` 提问，不增加公开接口或强制联网。
- 检索从每轮最新公开元数据中做关键词与中文分词匹配；显式标题优先，泛推荐在同等匹配时个人作品优先。只沿用最近助手引用作追问线索，切换主题不沿用先前用户问题的关键词。
- 本轮没有匹配作品就返回空作品依据，模型仍可使用公开个人介绍和运行模型标识回答。联网结果继续独立显示外部来源。
- 历史助手资料仅从本轮已成功读取详情的条目重建；列表后刚下线的作品也不会从历史重新进入上下文。

## 验证与使用

Node 24.4.0 下 `npm test`：65 项通过，静态检查通过。日志存于忽略的 `space-web/artifacts/n1-n2-tests.log`。使用现有 JavaScript 测试流程，没有增加依赖、修改数据库、安全配置或公开 API。

新浏览器/手机交互、剪贴板权限及真实模型新检索效果待验。当前运行的是用户启动的 Node 进程；前端文件刷新可读取，服务端检索改动需要下次正常重启网站后加载。没有停止用户进程，也没有重跑 M5、已有模型连接验收或付费请求。
