## 实际发现与处理

1. Halo 密码仅接受字母、数字和特定特殊字符。初次生成的 URL-safe 密码字符不符合规则，初始化被拒；改成允许字符组成的随机密码后初始化成功。
2. 默认存储策略没有启用文档类别，Markdown 和 TXT 均被拒。只增加 DOCUMENT 类别后，TXT 上传成功；未放开所有文件类型。Markdown 的浏览器 MIME 类型也不在默认文档白名单中，不能声称已支持直接上传 Markdown。
3. 文章管理 API 的前缀是 `/apis/api.console.halo.run/v1alpha1/posts`。网站公开内容适配使用另一套匿名公共接口，未向浏览器暴露后台凭据。
4. AnnotationSetting 仅在所属激活主题或启动插件范围内显示。本地表单关联当前后台主题 `theme-earth`；更换后台主题时需重新关联。该后台关联不会改变独立网站的橙色视觉。
5. 当前沙箱内部分命令行进程无权访问本机 HTTP 或 Docker socket。浏览器和网站服务的真实访问正常；`halo:wait` 已改为识别权限错误，不再把这类错误误报为 Halo 未启动。
6. 自动化指针操作遇到平滑滚动后落点漂移；完成状态检查后改用实际 DOM 坐标对应的原生鼠标/触摸事件完成浏览验收，没有改动网站的视觉动画。
