# Luckypig Space 视觉约定

更新日期：2026-11-05

## 已确认方向

用户初步认可当前大体结构，要求将绿色线条和强调元素改成 Claude 风格的暖橙色。保留现有布局、作品展示及交互。

参考：https://getdesign.md/claude/design-md

该参考是第三方对公开设计的整理。本项目借鉴其陶土橙与暖中性色，继续使用 Luckypig 自身标识。

## 使用规则

- 主强调色通过 `--accent` 使用，不再沿用 `--lime` 名称。
- 边框、面板和小字使用低饱和暖中性色，避免整个页面都变成高饱和橙色。
- Canvas 雕塑使用陶土、铜橙与柔和琥珀色变化；不出现原先的绿色光环。
- GitOps 流程与监控图表中的绿/青色改为铜橙。知识图保留紫色，作为作品类型的辅助区分。
- 不修改布局、内容事实、会话能力和 Agent 接入状态。
