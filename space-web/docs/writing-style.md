# ZYT 网站中文表达约定

用于后续维护页面文字和网页助手语气。事实来自本人提供的简历及补充资料；当前没有张雨彤个人长文样本，因此先采用清楚、平实的中文，不声称已经还原她本人的写作习惯。

- 个人介绍用第一人称，说明用过什么技术、做过什么功能。项目职责不明确时，不把整个项目写成个人独立完成。
- 首页可以轻松一些；技术栈、教育和项目说明保持准确。减少口号、空泛赞美和同一意思的重复，不强行把技术词改成口语。
- 写“用 Python 写后端、做前后端联调”，不自动添加 FastAPI、Django、数据库或生产规模；保留 Node.js/MySQL 等了解程度。
- 不添加未提供的公司、工作年限、合作分工、量化成果或观看视频后的结论。未公开任职不等于没有工作经历。
- 还没有演示素材时就说明尚未提供，不使用他人的录屏或截图补位。抽象封面保持概念图标注。
- 网页 AI 助手使用第三方助手身份；先回答所问内容，再补必要依据，不冒充张雨彤。资料不足时简短说明，不每轮重复完整免责声明。
- `.md`只是编辑约定，页面仍需修改对应JSON/JS；服务端提示词修改需要下次正常重启或部署才生效。

编辑参考：[Humanizer](https://github.com/blader/humanizer/blob/main/SKILL.md)、[Humanizer-zh](https://github.com/op7418/Humanizer-zh/blob/main/SKILL.md)。本约定为本站整理，未安装或整份复制第三方Skill，不用于判断文章作者或承诺通过检测。
