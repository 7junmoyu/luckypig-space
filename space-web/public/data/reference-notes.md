# AI / DevOps 参考案例笔记

整理日期：2026-11-05。本文件根据项目公开资料整理，用于 Luckypig Space 原型，不是站主的原创项目说明或真实履历。

## ComfyUI：生成式工作流

节点图可以把输入、模型和生成步骤组织起来，帮助理解生成式创作的过程。个人作品页可以将最终视觉、参数、过程说明与参考链接放在一起。

来源：https://github.com/Comfy-Org/ComfyUI

## Argo CD：声明式交付

Argo CD 面向 Kubernetes，使用 GitOps 方式组织持续交付。用流程图呈现配置、版本和同步关系，可以帮助访客理解工程项目。

来源：https://argoproj.github.io/cd/

## LangChain：知识与 Agent

LangChain 提供构建 LLM 应用与 Agent 的组件。本原型借用知识助手这一概念，展示公开资料如何通过对话被发现；当前没有实际部署该框架。

来源：https://github.com/langchain-ai/langchain

## Grafana：信号可视化

Grafana 可用于连接数据源并展示指标、日志与追踪。本站对应封面是自行绘制的演示图表，不反映真实系统状态。

来源：https://github.com/grafana/grafana
