02 / WEB SEARCH

让答案连接网络

使用 Tavily 搜索网页摘要，再交给当前模型回答；外部来源会显示为可点击链接。开启后，访客仍可逐轮选择是否联网。

需要独立的 Tavily Key。联网会将当前问题发送给搜索服务，并可能消耗搜索额度；未配置时保持关闭。

Key 仅存放在网站服务端，保存后不回显。当前生成中的回答继续使用原配置。模型原生协议与特殊参数的兼容性以连接测试为准。
